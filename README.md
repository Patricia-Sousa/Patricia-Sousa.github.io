# Portefólio Patrícia Sousa

Portefólio profissional de **Patrícia Isabel Amaral de Sousa**, desenvolvido para apresentação do percurso técnico, académico e profissional nas áreas de Informática, Programação, Desenvolvimento Web, Sistemas de Informação, Redes Locais e Bases de Dados.

## Sobre o projeto

Este projeto tem como objetivo reunir, numa plataforma web, a informação profissional relevante, incluindo:

- apresentação pessoal;
- currículo profissional;
- percurso académico e formativo;
- competências técnicas;
- projetos desenvolvidos;
- contactos profissionais;
- download do currículo em PDF.

O portefólio foi concebido com uma identidade visual inspirada em ambientes técnicos e terminais de sistema, utilizando uma estética moderna, minimalista e tecnológica.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages
